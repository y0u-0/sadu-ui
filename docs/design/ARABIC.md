## Voice

- Buttons and menu items use the verbal noun: حفظ، إلغاء، تنزيل.
- Instructions use the imperative: اكتب، ابحث.
- System messages use the light passive: حُفظ، أُرسلت.
- Digits are Western by default. `lang="ar-u-nu-arab"` switches to Arabic-Indic digits.
